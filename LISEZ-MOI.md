# Version « sans dossiers » pour GitHub

Tous les fichiers sont à la racine : on les glisse tous d'un coup dans GitHub (Ctrl+A dans le dossier extrait).
Dernière étape : ouvrir `build.yml` sur GitHub, cliquer sur le crayon, remplacer son nom par `.github/workflows/build.yml` et valider. La construction démarre alors toute seule.
